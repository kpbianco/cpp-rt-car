# Architecture Decision Records

Accepted decisions define the target architecture. An accepted decision can
precede its implementation; each record names the current mismatch and the
roadmap milestone that resolves it.

| ADR | Decision |
| --- | --- |
| [0001](0001-one-executor-boundary.md) | Use one CPU executor boundary |
| [0002](0002-host-driven-time.md) | Make host-driven time the default embedding mode |
| [0003](0003-device-backend-boundary.md) | Keep devices behind a bounded backend ABI |
