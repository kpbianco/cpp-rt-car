## Engine API and interface review

- The only approved exact-version low-level surfaces are
  `Async/Fundamental/Task.h` and `Async/Fundamental/Scheduler.h`, specifically
  `LowLevelTasks::FTask`, `TryLaunch`, `TryExpedite`, cancellation used by the
  test rejection seam, and `IsCompleted`. No Unreal Private header was found.
- All remaining engine use is through public Core surfaces:
  `FMemory::Malloc`, `FMemory::GetAllocSize`, `FMemory::Free`,
  `FPlatformTime::Cycles64`, `FPlatformTime::GetSecondsPerCycle64`, ordinary
  module interfaces, and automation interfaces.
- The runtime module remains passive. Startup/shutdown create no Runtime,
  world/delegate registration, worker, registry, or unload protocol.
- The plugin links the separately built relocated static `rtfw_runtime` and is
  absent from the default CMake target, component, installed-header, and alias
  inventories. No RTFW implementation source is compiled into the module and
  no experimental loader dependency was added.
- Job slots, copied jobs, engine task nodes, control words, generation state,
  and counters are instance-owned and capacity-bounded. Submit scans at most
  the configured power-of-two capacity and has no retry, wait, spill, inline
  fallback, or adapter-owned allocation.
- The provider owns at most the three existing active Runtime regions, checks
  requested size/alignment and allocator extent, independently repeats the
  extent observation, and leaves resident, locked, pinned, guard, huge-page,
  prefault, NUMA, and physical facts unclaimed. Failed rollback retains token
  ownership for retry; release clears ownership once.
- The clock clamps concurrent observations to a monotonically nondecreasing
  integer-nanosecond value, checks finite/range/rounding conversion, rejects
  engine-owned sleep, and supports only host-driven step. Frame conversion
  keeps simulation delta separate from optional clock-domain deadline and
  nominal-release values.
- Stable C ABI v8, device ABI v1, extension ABI v1, SONAME, Runtime interfaces,
  status values, schemas, default package inventory, support matrices, release
  1.2.1, and Apache-2.0 were not changed.
