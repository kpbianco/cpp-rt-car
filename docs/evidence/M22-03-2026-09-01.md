## Changed and preserved invariants

M22-03 adds only additive C++ closure/action/replay surfaces. The stable C ABI,
installed header inventory, existing artifact constants/codecs, release version,
and support matrices are unchanged. Disabled closure remains the M22-02 path.

Runtime rollback is limited to the Runtime-owned immutable live-control
generation, provisional mailbox ownership, action/journal state, and conditional
checkpoint state. It cannot undo arbitrary application, backend,
external-process, or physical-device side effects. Replay payload bytes exist
only in an explicit caller-requested trusted artifact; action telemetry remains
payload-free. Replay bypasses producer timing by reconstructing validated
post-checkpoint candidates and exact survivor payloads at their boundary.
