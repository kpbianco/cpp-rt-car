## Changed and preserved invariants

Changed:

- Runtime-owned thread construction now uses one internal native-thread abstraction and injected/native policy provider.
- Startup has a global policy result barrier and deterministic reverse rollback.
- Thread role reports now retain applied/read-back policy, aggregate instance counts, mismatch, fallback, and native error state.
- Runtime-owned idle loops honor resolved spin/yield/park behavior.
- Device lane creation/policy verification is separated from backend initialization, while lane stop is separated from cleanup retry to preserve M14.1 semantics.

Preserved:

- Runtime-owned lanes remain fixed at finalized cardinality; no hidden, detached, spill, emergency, or per-frame threads exist.
- Host callbacks cannot run before committed startup, and declared runtime lanes gain no file I/O, blocking mutex in executor work, unbounded spill, or ordinary heap allocation after start.
- Runtime instances retain instance-owned providers, gates, reports, queues, and wake state.
- The C ABI, device ABI, SONAME, schemas, release/license, installation inventory, portability/support matrices, and qualification boundary are unchanged.
- CUDA/XDMA backends and experimental SimCore/scheduler/fiber/plugin paths remain outside `rtfw::runtime`.
